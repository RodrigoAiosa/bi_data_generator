🔗 Gerador de links por grupo

Cole os nomes dos seus grupos (um por linha). A página cria um link para cada grupo, com a etiqueta feita a partir do nome. Assim, nas métricas você vê qual grupo trouxe cada visita.

Dica: cada pessoa que clicar no link do grupo é contada naquele grupo. Se alguém encaminhar a mensagem para outro grupo, a visita continua contando para o grupo original do link. As etiquetas ficam visíveis na barra de endereço, então use nomes que você aceite que os membros vejam.
